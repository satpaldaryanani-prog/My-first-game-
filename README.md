# Cat Football Game 🐱⚽

A mobile football (soccer) game featuring adorable Mofusland-inspired cat characters with EA Mobile-style gameplay and controls.

## 📋 Project Overview

**Cat Football** combines the cuteness of Mofusland-style characters with the competitive gameplay of mobile football games like FIFA Mobile. Players collect adorable cat characters, build teams, and compete in quick, engaging 3v3 matches.

### Key Features

- 🐾 **Cute Cat Characters**: Mofusland-inspired chibi-style cats with unique personalities
- ⚽ **Accessible Gameplay**: EA Mobile-style controls optimized for mobile
- 🎮 **Multiple Game Modes**: Quick Match, Tournament, Career Mode, and Real-Time PvP
- 🌟 **Collection System**: Collect and evolve 50+ unique cat characters
- 🎯 **Unique Mechanics**: Curiosity System, Meowmentum Chains, Cat Formations
- 🏟️ **Customization**: Upgrade stadiums, customize teams, unlock special abilities
- 🌍 **Multiplayer**: Real-time PvP matches with skill-based matchmaking

## 🎮 Core Gameplay

### Match Format
- **3v3 Matches**: Quick, intense gameplay (2-3 minutes per match)
- **Simple Controls**: Virtual joystick + action buttons, gesture controls, or hybrid
- **Real-Time Action**: Fast-paced football with cat-themed twists

### Unique Cat-Themed Mechanics

#### 🐈 Curiosity System
Cats get distracted during matches by environmental events (birds, laser pointers, cardboard boxes), creating hilarious and unpredictable moments.

#### ⚡ Meowmentum Chains
Build combos through successful plays to unlock powerful team boosts and special effects.

#### 🏰 Territory Marking
Home stadium advantage system where your cats perform better in familiar territory.

#### 🎭 Cat Formations
Beyond standard formations - unlock unique cat-themed tactics like "Cardboard Box Defense" and "Cat Tower Attack."

## 🐱 Character System

### Cat Stats (Cat-Themed)
- **Pounce Power**: Shooting strength
- **Whisker Precision**: Passing accuracy
- **Tail Balance**: Dribbling and agility
- **Claw Grip**: Ball control
- **Nine Lives**: Stamina and recovery
- **Purr-suasion**: Crowd effect bonus

### Rarity Tiers
- **Common** (60%): Solid base stats, 2 evolution tiers
- **Rare** (30%): Enhanced stats, 3 evolution tiers
- **Epic** (9%): Powerful stats, unique abilities
- **Legendary** (1%): Elite stats, exclusive abilities

### Evolution System
Cats evolve from Kitten → Adult → Champion → Legend (legendary only), gaining new abilities and enhanced stats.

## 🎯 Game Modes

1. **Quick Match** - Fast 3v3 matches vs AI
2. **Tournament Mode** - Compete in bracket tournaments
3. **Career Mode** - Build your team from scratch
4. **Training Mode** - Practice skills and test strategies
5. **PvP Multiplayer** - Real-time matches against other players
6. **Ranked Seasons** - Competitive ladder with rewards

## 🛠️ Technology Stack

### Client
- **Engine**: Unity 2022.3 LTS
- **Rendering**: Universal Render Pipeline (URP)
- **Language**: C#
- **Networking**: Mirror Networking (for multiplayer)
- **Platform**: iOS 13+, Android 7.0+

### Backend
- **MVP**: Firebase (Auth, Firestore, Cloud Functions)
- **Scale**: Custom Node.js backend with PostgreSQL
- **Matchmaking**: Redis for queue management
- **Analytics**: Firebase Analytics + Unity Analytics

### Tools
- **Version Control**: Git + Git LFS
- **CI/CD**: GitHub Actions
- **Testing**: Unity Test Framework
- **Project Management**: GitHub Projects

## 🎨 Art Style

### Mofusland-Inspired Aesthetic
- Oversized heads (1:1 or larger head-to-body ratio)
- Large, expressive eyes with sparkles
- Round, fluffy chibi proportions
- Soft, cloud-like fur texture
- Cute sports accessories

### Visual Style
- Clean, vibrant colors
- Minimal shading (flat/cel-shaded)
- Expressive animations
- Particle effects for special moves

## 💰 Monetization (F2P)

### Player-Friendly Approach
- **Fair Gacha**: Guaranteed drops, pity system
- **F2P Viable**: All cats obtainable without paying
- **Skill > Cards**: Player skill matters more than rarity
- **Cosmetics Focus**: Premium skins, jerseys, stadiums

### Revenue Streams
1. Character packs (with guarantees)
2. Battle Pass / Season Pass
3. Cosmetic items (skins, accessories, stadiums)
4. Starter packs (low-cost, high value)
5. Optional ads (rewarded videos)
