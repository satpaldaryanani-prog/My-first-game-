# Cat Football Game - Game Design Document

## Overview
A mobile football (soccer) game featuring adorable Mofusland-inspired cat characters with EA Mobile-style gameplay and controls.

## Game Concept

### Core Theme
- **Genre**: Sports - Football/Soccer
- **Platform**: Mobile (iOS/Android)
- **Art Style**: Cute, chibi-style cats inspired by Mofusland characters
- **Target Audience**: Casual mobile gamers, cat lovers, sports fans (ages 8+)

## Character Design

### Mofusland-Inspired Cat Characters
- **Art Style**: Round, fluffy cat designs with oversized heads and small bodies
- **Customization**: Different cat breeds, colors, accessories
- **Player Types**:
  - Striker Cats (fast, agile)
  - Defender Cats (strong, sturdy)
  - Goalkeeper Cats (quick reflexes)
  - Midfielder Cats (balanced stats)

### Character Features
- Expressive animations (happy, determined, celebrating, disappointed)
- Unique abilities per cat type
- Collectible cat cards (similar to FIFA Mobile)
- Level-up and evolution system

## Gameplay Mechanics

### Core Football Gameplay
1. **Match Types**:
   - Quick Match (3v3 or 5v5)
   - Tournament Mode
   - League Play
   - PvP Multiplayer
   - Training Mode

2. **Match Duration**:
   - Quick matches: 2-3 minutes
   - Full matches: 5-6 minutes

3. **Team Formation**:
   - Customizable formations (3-1-1, 2-2-1, etc.)
   - Substitute cats on bench
   - Captain selection for stat bonuses

### EA Mobile-Style Controls

#### Control Scheme Options:

**Option 1: Classic Controls**
- Virtual joystick (left side) - Movement
- Action buttons (right side):
  - Pass button
  - Shoot button
  - Sprint button (hold while moving)
  - Tackle/Pressure button (defending)
  - Through ball button

**Option 2: Gesture Controls**
- Swipe to pass/shoot (direction + power)
- Tap to switch players
- Hold and drag for movement
- Quick swipe up for lob passes

**Option 3: Hybrid**
- Combine joystick movement with gesture shooting

#### Control Features:
- Auto-switching to nearest player
- Pass assistance levels (beginner, intermediate, expert)
- Shot power meter
- Tactical buttons (offside trap, team press)
